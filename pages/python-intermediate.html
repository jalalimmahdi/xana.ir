برنامه نویسی پایتون متوسط

عبور از مبانی و ورود به کدنویسی حرفه ای تر با مدیریت خطا، ماژولار کردن پروژه، کار با محیط مجازی و تست نرم افزار.

اطلاعات دوره

این دوره بر موضوعات کاربردی Python Standard Library شامل exceptions، packages، venv، unittest، logging و کار با داده های ساختارمند تمرکز دارد.

سطح: متوسط مدت: 14 جلسه پیش نیاز: پایتون مقدماتی

سرفصل های اصلی

  • طراحی توابع پیشرفته و الگوهای ماژولار
  • مدیریت خطا و Exception Handling حرفه ای
  • کار با pathlib، datetime، collections و itertools
  • محیط های مجازی، نصب پکیج و مدیریت وابستگی
  • مستندسازی و تست واحد با unittest
  • طراحی پروژه نیمه واقعی با ورودی/خروجی فایل
